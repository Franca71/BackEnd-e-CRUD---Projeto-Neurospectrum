# BackEnd-e-CRUD---Projeto-Neurospectrum

NeuroSpectrum – Backend
Sobre o Projeto
O NeuroSpectrum é um projeto acadêmico desenvolvido com o objetivo de auxiliar profissionais da saúde mental no gerenciamento de informações clínicas de pacientes com transtornos psiquiátricos. A plataforma visa centralizar dados essenciais para o acompanhamento terapêutico, proporcionando maior organização, eficiência e suporte à tomada de decisão clínica.
Backend
O backend é responsável pela implementação das regras de negócio, integração com o banco de dados e disponibilização dos serviços necessários para o funcionamento da aplicação por meio de uma API REST.
Funcionalidades Implementadas
Atualmente, o projeto possui operações de CRUD (Create, Read, Update e Delete) implementadas para os seguintes módulos:

Objetivo Acadêmico
Este projeto foi desenvolvido para fins acadêmicos, visando aplicar conceitos relacionados ao desenvolvimento backend, modelagem de banco de dados, construção de APIs REST e boas práticas de engenharia de software.
